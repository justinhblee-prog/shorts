# BUILD-00025 — Bind YouTube upload bytes to human approval

**Date:** 2026-11-16  
**Status:** Merged to `main`; CI passed.

## Change

Renderer staging computes a streaming SHA-256 digest and byte length. The fingerprint is persisted in rendering artifact metadata and captured in the immutable human review snapshot. Manual restaging persists changed fingerprint metadata and returns the production run to `review_pending`, requiring a new human decision.

Before upload, the publisher requires the staged filename, byte count and SHA-256 to match the approved snapshot. Verified bytes are copied through a no-follow file descriptor into a private temporary snapshot, and YouTube receives that immutable copy rather than the mutable staging path. The temporary snapshot is removed during cleanup.

## Regression coverage

- SHA-256 returned by the media stager matches the downloaded payload.
- Mutating staged media after approval blocks upload before the provider insert call.
- Supplying a different staged filename blocks upload even if bytes are identical.
