# NEXUS STUDIO PRO — 제품 기획 및 요구사항

- 문서 버전: v0.1
- 기준일: 2026-11-20
- 제품명: NEXUS STUDIO PRO
- 제품 유형: 글로벌 숏폼 콘텐츠 운영·제작·성과·수익 최적화 플랫폼

## 1. 제품 개요

NEXUS STUDIO PRO는 여러 브랜드와 시장에서 숏폼 콘텐츠 운영을 통합 관리하는 운영 플랫폼입니다. 주제 발굴부터 경쟁 채널 조사, 수익성 시나리오 분석, 제작 작업 생성, AI 공급자 기반 제작, 사람의 검수·승인, 플랫폼 게시, 성과 수집, 실제 수익·비용 장부 및 성과 분석까지 연결하는 것이 목표입니다.

핵심 운영 원칙은 “Automate the workflow. Verify the evidence. Optimize for real profit.”입니다. 자동화는 반복 업무를 줄이되, 실제 근거가 없는 성과·수익을 만들어내거나 사람의 승인 절차를 우회해서는 안 됩니다.

## 2. 목표와 성공 기준

### 제품 목표
- 글로벌 시장과 복수 브랜드를 한 운영 화면에서 관리합니다.
- 주제·경쟁 콘텐츠·성과 데이터를 출처와 함께 수집합니다.
- 제작 파이프라인을 작업 큐와 Worker Lease로 안정적으로 실행합니다.
- 검수 이력과 승인 증거를 남기고 승인된 콘텐츠만 게시 단계로 넘깁니다.
- 플랫폼 성과와 실제 거래 장부를 분리해 수익성을 평가합니다.
- 반복 실행, 장애 복구, 감사 추적이 가능한 운영 기반을 제공합니다.

### 핵심 KPI
- 검증된 순수익 및 ROI (실제 장부 입력 기반)
- 브랜드별 제작 처리량과 검수 통과율
- 제작 1건당 실제 비용 및 운영 소요시간
- 플랫폼별 게시 성공률과 데이터 수집 커버리지
- 작업 실패·재시도·복구율 및 Worker Lease 안정성
- 주제 추천의 실제 성과 검증률

KPI 수치 목표와 상용화 기준은 아직 별도 승인·확정이 필요합니다. 예측 조회수·RPM·수익은 실제 수익으로 취급하지 않습니다.

## 3. 브랜드 포트폴리오

현재 코드 문서에 정의된 10개 브랜드:
1. Brain Glitch — 신경과학·심리
2. Silent Signals — 관계·비언어 심리
3. Unseen Truth — 역사·숨겨진 맥락
4. Dark Files Global — 우주·심해·미스터리
5. 99% Missed — 생활 지식·생산성
6. Money Glitch — 경제·금융
7. Secret Vault 24 — 기업·경제 비밀
8. Future Leak — AI·미래 기술
9. 30Sec Shift — 건강·수면·장수
10. Why Nobody Tells — 사회·비즈니스 인사이트

브랜드별 세부 언어·지역·편집 규칙은 backend의 브랜드 레지스트리 구현을 기준으로 관리합니다. 이 목록만으로 각 브랜드의 상표권·도메인 권리를 확보했다고 간주하지 않습니다.

## 4. 사용자와 주요 사용 시나리오

### 운영자 / 관리자
- 브랜드·시장별 운영 상태 확인
- API 연결 및 사전 점검
- 예약 제작·큐 일시중지·검증 후 재개
- 실제 비용·수익 거래 기록 및 증빙 참조 관리
- 운영 이벤트·오류·복구 이력 확인

### 콘텐츠 기획자 / 프로듀서
- 트렌드 및 경쟁 채널 조사
- 수익성 시나리오 평가 및 우선순위 검토
- 브랜드·시장·언어·플랫폼을 지정한 제작 요청
- 제작 결과물과 출처 확인

### 검수자
- 생성된 영상·오디오·스크립트 검토
- 승인·반려·수정 요청 및 사유 기록
- 합성 미디어·저작권·정책 증빙 확인

### 게시 담당자
- 승인된 결과물 확인
- 연결된 플랫폼 계정 및 게시 권한 확인
- 업로드·게시 상태 확인과 모호한 결과의 수동 대조

현재 역할/권한 체계는 코드에 구현된 API 권한 모델을 기준으로 하며, 외부 조직 SSO·세분화된 고객별 테넌트 모델이 완성되었다는 의미는 아닙니다.

## 5. 기능 범위

| 영역 | 핵심 요구사항 | 현재 확인된 상태 |
|---|---|---|
| 브랜드 운영 | 10개 브랜드 프로필, 활성화, 지역·언어 검증 | Core 코드 및 테스트 존재 |
| 트렌드 인텔리전스 | Google News RSS, Hacker News 수집 | Provider/저장/API 구현 기록 존재 |
| 경쟁 분석 | YouTube 채널·영상 공개 지표 | API/저장 구현, 실제 키 연동 미검증 |
| 기회 평가 | 수익·비용 시나리오, 근거 기반 점수 | 계산·저장/API 구현, 실제 수익 예측력 미검증 |
| AI 제작 | 스크립트 → 음성 → 영상 공급자 연결 | Provider-neutral orchestration 구현, 실공급자 생성 미검증 |
| 작업 실행 | Durable Queue, Worker Lease, 재시도·복구 | 다수 BUILD 개선 및 자동 테스트 기록 |
| 검수·승인 | 불변 결정 이력, 아티팩트 스냅샷 | 구현 기록 존재, 실제 운영 권한 구성 별도 |
| YouTube | OAuth, 비공개 업로드, 공개 지표·Analytics | 어댑터/수집기 구현 기록, 실계정 검증 미완료 |
| TikTok | 연결·게시 및 Display API 지표 | 기능별 구현 기록, 실계정·권한 검증 미완료 |
| 재무 | 출처 참조 장부, 수익·비용·ROI | 장부 구현, 자동 금융기관/제휴 정산 미완료 |
| 예약 | 반복 스케줄과 durable outbox | 구현 기록 존재, 실운영 장애 훈련 미완료 |
| 대시보드 | Studio, Intelligence, Review, Operations | 단일 페이지 UI 존재, 현재 UI PR 스택 검증 진행 중 |
| 백업·복구 | 백업, 체크섬, 암호화 옵션, 복원 | Compose CI 통합 테스트 기록, 운영 호스트 복원 미검증 |

## 6. 사용자 경험 / 정보 구조

현재 프런트엔드 단일 페이지의 주요 업무 영역:
1. **Studio** — 브랜드별 제작 요청과 콘텐츠 제작 운영
2. **Intelligence / Discovery** — 트렌드, 경쟁 채널, 기회 평가
3. **Review** — 검수 대기, 승인·반려·수정, 플랫폼 연결·게시 상태
4. **Operations** — 예약, 큐 운영, 실제 재무 장부, 성과 인사이트, 연동 준비 상태

UI 개발은 기존 기능·DOM ID·API 연동을 보존하면서 시각적 계층과 사용성을 개선하는 방식입니다. 화면 시안만으로 기능 완료를 선언하지 않습니다. 실제 브라우저에서 데스크톱·모바일을 확인하고, 상호작용·오류·빈 상태를 검증해야 합니다.

## 7. 핵심 정책 및 비기능 요구사항

- 게시 전 사람의 승인 필요. YouTube 업로드는 현재 구현상 private 고정 정책.
- TikTok 게시의 공개 범위·동의 조건은 실제 API 계약과 계정 권한을 확인해야 함.
- 실제 수익과 예상 수익을 명확히 분리.
- 측정되지 않은 조회수·RPM·검색량·수익은 null/미확인으로 유지.
- 출처 URL·라이선스·합성 미디어 공개 등 정책 증빙을 검수 흐름에 연결.
- 인증·역할·권한은 fail-closed. 비밀키·OAuth 토큰은 저장소에 커밋하지 않음.
- 외부 미디어는 HTTPS·허용 호스트·크기·검사 정책을 통과해야 함.
- Worker/collector의 lease token과 fencing을 통해 오래된 실행 결과가 상태를 덮어쓰지 못하게 함.
- 로그와 감사 기록에는 비밀정보를 기록하지 않음.

다음은 문서만으로 확정하지 말고 별도 의사결정이 필요합니다.

- 최종 AI 공급자 목록, 비용 상한, 품질 평가 기준
- 자동 게시 허용 범위와 플랫폼별 정책 검토
