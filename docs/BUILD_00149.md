# BUILD-00149 — recommendation cohort dimension validation

## Scope

Validate outcome metadata used to construct recommendation evaluation cohort keys.

## Changes

- Normalize job IDs, platform labels and cohort dimensions to bounded, trimmed strings.
- Reject mapping/list/boolean/other non-string values for categorical dimensions.
- Prevent malformed provider metadata from becoming unhashable cohort keys and crashing evaluation.
- Keep invalid dimensions from entering cohort comparisons while preserving valid outcome counts.
- Add regression coverage for unhashable, oversized and whitespace-padded dimensions.
