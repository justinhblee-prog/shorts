# BUILD-00089 — safe production cancellation

- Synchronize queue and production lifecycle records during cancellation.
- Permit production cancellation only before the human-review handoff.
- Treat cancellation of a running production job as externally ambiguous: revoke the lease, mark both records cancelled with an explicit reconciliation requirement, and pause production.
- Preserve ordinary cancellation for non-production queue jobs.
- Add tests for queued cancellation, running ambiguous cancellation and review-handoff rejection.

Tests exercise SQLite state transitions and lease fencing; they do not cancel or reconcile a real third-party provider job.
