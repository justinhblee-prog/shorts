# BUILD-00085 — TikTok OAuth callback input bounds

## Scope
Bound authorization code and state inputs at both the HTTP route and OAuth manager boundary.

## Changes
- Limit callback authorization codes to 4,096 printable ASCII characters.
- Limit state to 256 URL-safe characters and reject malformed state before hashing or database access.
- Add FastAPI query parameter limits for code, state, error and error_description.
- Validate code and state before consuming the one-time state record, so malformed input cannot burn a legitimate OAuth transaction.
- Add tests proving oversized/control-containing values are rejected without transport calls or state consumption.

## Validation boundary
Unit tests verify input validation and one-time-state preservation. They do not establish live TikTok OAuth callback compatibility or external account authorization.
