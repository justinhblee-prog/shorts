# BUILD-00151 — bounded recommendation trend identifiers

## Defect
The recommendation exposure writer accepted non-empty trend identifiers longer than 160 characters, while production-selection linking rejects identifiers longer than 160 characters. Such candidates could be persisted but could never be linked to a production job.

## Change
- Apply the existing 160-character identifier contract at exposure ingress.
- Exclude overlong identifiers before database persistence.
- Preserve valid candidates in the same exposure.
- Add regression coverage confirming valid identifiers remain selectable.

## Safety boundary
Ranking score adjustment remains disabled. This validates local persistence behavior only; no live provider, account, deployment or revenue validation is claimed.

## Validation
GitHub Actions validation is recorded in the pull request after the full scripts/validate.sh workflow completes.
