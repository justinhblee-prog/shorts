# BUILD-00151 — malformed retention-curve payload isolation

## Finding
`_normalized_outcome` iterated `audience_retention_curve` without checking its container type. A provider response containing `null` or a scalar raised `TypeError` and could abort the complete evaluation request.

## Change
- Iterate retention points only when the supplied curve is a list.
- Treat malformed curve containers as unavailable retention evidence while retaining separately validated metrics.
- Add regression tests for null, numeric, string and mapping payloads.

## Validation
- GitHub Actions `scripts/validate.sh`: pending.
- This is defensive input handling; no live provider/account/deployment validation is claimed.
- Ranking score adjustment remains disabled.
