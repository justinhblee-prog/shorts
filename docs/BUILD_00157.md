# BUILD-00157 — historical performance aggregate validation

## Finding
Historical performance enrichment is optional display-only context, but the ranking path assumed each brand aggregate was a mapping and coerced sample counts with `int()`. A null/scalar aggregate or malformed count (including a boolean) could abort ranking for an otherwise valid trend.

## Change
- Treat non-mapping historical aggregate containers and non-dictionary aggregate collections as unavailable evidence; reject malformed optional video/cohort collections at the enrichment boundary.
- Accept sample counts only as nonnegative integers, excluding booleans; invalid values default to zero.
- Preserve editorial scores and the existing zero ranking-score adjustment.
- Add regression coverage for null/scalar aggregate payloads, malformed count values and invalid top-level enrichment containers.

## Validation
- GitHub Actions validation: pending.
- No live Analytics provider/account/deployment validation is claimed.
- Recommendation ranking score adjustment remains disabled.
