# BUILD-00084 — bounded trend-source HTTP fetches

## Scope
Harden the shared HTTP transport used by Google News RSS and Hacker News collection.

## Changes
- Limit every trend-source response to 512 KiB and read at most one byte beyond the limit to detect overflow.
- Validate HTTP status and Content-Length; reject negative, malformed, oversized or mismatched lengths.
- Disable automatic redirects so an unexpected source redirect cannot forward the collector to an arbitrary destination.
- Return bounded, sanitized transport errors rather than upstream response bodies.
- Add regression tests for oversized payloads, malformed/mismatched lengths, redirects and non-success statuses.

## Validation boundary
Transport tests use mocked HTTP responses. They do not establish source availability, feed correctness, real-world collection quality or third-party service SLAs.
