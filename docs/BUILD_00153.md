# BUILD-00153 — bounded symmetric recommendation exposure deduplication

## Finding
Exposure deduplication searched only for matching records at or after the incoming timestamp minus 60 seconds, without an upper bound. A new backdated exposure could therefore be incorrectly collapsed into a matching record created arbitrarily far in the future. In addition, accepted timestamps retained their original UTC offsets, making lexicographic SQL timestamp-window comparisons unsafe across different offsets.

## Change
- Restrict duplicate matching to the inclusive ±60-second window around the incoming exposure timestamp.
- Normalize all accepted timestamps to UTC before persistence, making stored ISO timestamp ordering consistent.
- Add regression coverage for a later exposure followed by a backdated one, the one-minute boundary and equivalent instants with different timezone offsets.
