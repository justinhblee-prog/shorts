# BUILD-00153 — malformed audience-retention payload isolation

## Defect

The recommendation evaluation normalizer iterated directly over `audience_retention_curve`. A provider or upstream adapter returning a scalar (for example `null`, a number, a boolean, or a string) caused a `TypeError` and aborted evaluation of the complete performance batch, even when the same outcome contained valid views/hour or other analytics metrics.

## Change

- Accept retention points only when the outer value is a list.
- Treat malformed outer containers as unavailable retention evidence.
- Continue normalizing other metrics for the same outcome.
- Keep missing retention checkpoints null; do not synthesize a curve.

## Validation

- Regression test covers null, numeric, boolean and string curve containers.
- Confirms the selected job and valid views/hour metric remain measurable, while retention checkpoints remain null.
- Full GitHub Actions `scripts/validate.sh` result is pending.

## Scope and limitations

This is input-resilience hardening only. It does not verify live YouTube/TikTok provider payloads, enable ranking-score changes, or establish causal recommendation lift.
