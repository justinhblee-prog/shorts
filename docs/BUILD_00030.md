# BUILD-00030 — Platform-aware manual and scheduled production

**Date:** 2026-11-16  
**Status:** Implementation on branch; CI pending.

## Change

- Add YouTube Shorts / TikTok selection to the standard production request.
- Add platform selection to recurring schedule creation.
- Persist the selected platform as `platforms:["youtube"]` or `platforms:["tiktok"]` in the schedule payload.
- Preserve the payload unchanged through the durable schedule outbox and queue dispatch.
- Display the selected platform in the schedule dashboard.
- Keep YouTube as the default for existing schedules and clients that omit the field.

## Regression coverage

- API models accept platform selection for production and schedules.
- Scheduler dispatch preserves the TikTok platform list in the queued job.

## Validation boundary

CI pending. External generation providers and live platform credentials remain separate operational prerequisites.
