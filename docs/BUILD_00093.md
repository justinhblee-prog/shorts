# BUILD-00093 — enforce TikTok approved-media fingerprint at publish boundary

## Problem
TikTok publishing already calls the shared verified-media snapshot helper, which is designed to reject staged bytes that differ from the fingerprint captured at human approval. The regression suite did not explicitly prove that a post-approval media mutation is rejected before any TikTok API request.

## Changes
- Add a regression test that mutates the staged media after the approval record has captured its SHA-256 and byte length.
- Assert that the TikTok publisher rejects the media at the approval-integrity boundary.
- Assert that neither TikTok API initialization nor upload is attempted and no publication row is created.

## Validation
- This is a deterministic local regression test using the existing fake transport and fake media inspector.
- It does not make a real TikTok request or validate a live creator account.
