# BUILD-00150 — recommendation timestamp ingress validation

## Scope
Harden the recommendation exposure and production-selection persistence boundary against malformed timestamps and identifiers.

## Changes
- Validate exposure `generated_at` and production `selected_at` as bounded ISO-8601 strings before database operations.
- Normalize timezone-aware timestamps to ISO form and interpret naive timestamps as UTC.
- Reject malformed/non-string/oversized region labels before SQLite binding.
- Reject malformed production trend, brand and job identities without creating a selection link.
- Require platform labels to be strings matching the supported platform set.
- Add regression tests for malformed timestamps, regions and production identities.

## Safety boundaries
- Recommendation ranking score adjustment remains disabled.
- This change validates local persistence inputs only; it does not claim live YouTube/TikTok provider, account, deployment or production validation.
