# BUILD-00154 — trend ranking with no active brands

## Finding
The trend-ranking loop assigned its `region` variable only while iterating active brands, then referenced it after the loop. When the configured brand list was empty or all brands were inactive, the first trend raised `UnboundLocalError` instead of being returned as an unbranded candidate.

## Change
- Resolve the trend region before entering the active-brand loop.
- Preserve the existing behavior that allows trends to be ranked with no matching brand.
- Add regression coverage for an empty brand list and an all-inactive brand list.
