# BUILD-00154 — YouTube Analytics storage-boundary numeric validation

## Defect

The Analytics store's numeric helper converted booleans using Python's numeric coercion (`True` to 1 and `False` to 0). Its persistence boundary also accepted elapsed-video-time and audience-watch ratios above 1. The collector currently validates provider batches, but direct store callers and future adapters could persist invalid analytics evidence.

## Change

- Reject booleans in the shared numeric normalizer.
- Require elapsed-video-time and audience-watch ratios to be within the inclusive 0–1 interval before persistence.
- Continue allowing negative `relativeRetentionPerformance` values, as that API field is relative and may be negative.
- Preserve legitimate average view percentages above 100%.

## Validation

- Regression test calls the store directly with boolean counters, invalid retention coordinates, valid boundary coordinates and a valid average view percentage above 100%.
- Confirms unrelated valid metrics are retained and malformed values are omitted.
- Full GitHub Actions `scripts/validate.sh` result pending.

## Scope and limitations

This hardens local persistence validation. It does not claim live YouTube Analytics connectivity or validate a production OAuth account.
