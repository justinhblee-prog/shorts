# BUILD-00147 — recommendation outcome ingress validation

## Problem

The recommendation evaluation boundary accepted booleans as numeric outcomes, could overflow while converting arbitrarily large integers, and treated arbitrary retention curve entries as usable analytics. This could contaminate holdout diagnostics or crash evaluation on malformed provider data.

## Changes

- Add safe finite nonnegative numeric normalization that rejects booleans and catches conversion overflow.
- Enforce 0–1 bounds for engaged-view share and both retention coordinates.
- Keep average view percentage unbounded above because replayed viewing can legitimately exceed 100%.
- Normalize each outcome before deciding whether it is measured; malformed-only rows remain unmeasured.
- Ignore malformed performance containers and non-dictionary outcome rows.
- Add regression coverage for boolean, NaN, infinity, negative, overflow and valid >100% average-view-percentage values.

## Safety boundaries

- Evaluation remains observational and selection-biased.
- No ranking-score adjustment is enabled.
- No provider/live-account validation is claimed.
