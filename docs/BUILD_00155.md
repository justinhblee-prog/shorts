# BUILD-00155 — malformed trend batch isolation

## Finding
The ranking boundary assumes every trend and brand record is a dictionary and both batches are iterable lists. A single null, scalar or nested malformed feed entry can raise an attribute error while ranking, aborting valid candidates in the same batch. Non-list containers can also fail before ranking begins.

## Change
- Keep dictionary records and isolate malformed trend/brand entries at the ranking boundary.
- Treat non-list batch containers as empty input.
- Add regression tests proving valid records still rank when malformed records are present and malformed containers fail closed.
