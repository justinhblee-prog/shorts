# BUILD-00145 — strict recommendation evidence metric validation

## Problem

Recommendation context aggregation accepted Python booleans as numeric values and could include non-finite values in historical performance summaries. Audience-retention coordinates were not independently checked for both normalized bounds. Competitor view counts also accepted booleans because Python treats `bool` as an `int`.

## Changes

- Add strict finite, nonnegative numeric normalization that excludes booleans and catches conversion overflow.
- Require engaged-view share and audience-retention coordinates to be normalized ratios in the inclusive 0–1 range.
- Preserve average view percentage values above 100%, which may occur when viewers replay content.
- Ignore malformed interaction-rate inputs and competitor view counters.
- Add regression tests for boolean, NaN, infinity and out-of-range recommendation evidence.

## Safety boundaries

- Historical metrics remain contextual evidence only; no recommendation score or ordering is changed.
- No profitability, search-volume or demand claims are inferred from competitor counters.
- No live YouTube/TikTok provider validation is claimed.
