# BUILD-00088 — external media URL scheme validation

- Add one URL policy for media links and audio preview sources.
- Permit absolute HTTPS URLs only; reject javascript:, data:, file:, HTTP, malformed URLs and embedded credentials.
- Hide media links/previews when the URL fails validation.
- Use noopener and noreferrer for opened media links.
- Add static regression checks for both video rendering paths and audio preview.

Static source tests do not replace browser-level security testing or validate remote media availability.
