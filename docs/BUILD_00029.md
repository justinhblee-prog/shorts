# BUILD-00029 — Platform-specific performance and recommendation evaluation

**Date:** 2026-11-16  
**Status:** Implementation on branch; CI pending.

## Change

- Add TikTok performance analysis from owned-video Display API snapshots: view velocity and like/comment/share deltas, elapsed-time normalization, and comparable brand/region/topic/duration/format/publication-age cohorts.
- Add platform to recommendation exposure runs with additive SQLite migration. Deduplication, selected-production linking, and evaluation are scoped to the same platform.
- Add YouTube Shorts/TikTok platform selection to the trend recommendation workspace, plus a platform-specific holdout evaluation panel.
- Add platform to trend production drafts and set the production brief's platform list so policy preflight and subsequent publishing use the intended platform.

## Evaluation guardrails

- YouTube and TikTok outcomes are never mixed.
- TikTok metrics use only owned-video Display API data available to this integration: views, likes, comments and shares.
- TikTok audience retention, watch time and estimated revenue are unavailable in this collector and are not inferred.
- Recommendation ranking score adjustment remains disabled. At least five platform-specific exposure runs and comparable cohorts with three or more selected measured candidates are required for holdout evaluation; even then, the results remain observational and selection-biased.

## Validation boundary

CI pending. No recommendation score changes are enabled and no real production outcome data is fabricated.
