# BUILD-00087 — atomic TikTok metrics batches

- Validate every TikTok metrics row and counter before persistence.
- Reject duplicate, malformed and unrequested video IDs.
- Bound job/video identifiers and SQLite integer counters.
- Persist accepted response batches in one SQLite transaction so a malformed later row cannot leave earlier rows partially committed.
- Add regression tests for invalid late rows, duplicates and integer overflow.

Mocked transport tests do not prove live TikTok Display API availability, granted scopes or production metrics accuracy.
