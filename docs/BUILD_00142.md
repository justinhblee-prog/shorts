# BUILD-00142 — strict recommendation analytics outcome validation

## Problem

Recommendation evaluation accepted Python booleans as numeric analytics values because `bool` subclasses `int`. It also allowed malformed audience-retention coordinates to be treated as evidence. Invalid values could therefore inflate measured-outcome coverage and affect offline evaluation diagnostics.

## Changes

- Added a shared finite, nonnegative numeric validator that explicitly excludes booleans.
- Normalize view velocity and YouTube analytics metrics before outcome classification.
- Ignore malformed retention points and require both video-time and audience-watch ratios to be finite values in the inclusive 0–1 range.
- Keep valid average view percentage values above 100%; replay behavior can legitimately produce them.
- Added regression tests for boolean, NaN, infinity, negative and nonnumeric values, invalid retention coordinates, invalid-only selected outcomes and valid replay percentages.

## Safety boundaries

- No recommendation score, ranking order, production workflow, human approval, or publication behavior is changed.
- The evaluator remains observational and selection-biased; it is not a causal estimate.
- Automated CI does not prove live YouTube/TikTok provider connectivity or real audience outcomes.
