# BUILD-00028 — TikTok operator controls in the review workspace

**Date:** 2026-11-16  
**Status:** UI implementation on branch; CI pending.

## Change

- Add TikTok account connection/status controls to the human review workspace.
- Display creator nickname/username, maximum video duration and the supported privacy options from the creator-info API response.
- Add explicit TikTok private-publish action using the approved staged-media fingerprint and `SELF_ONLY` privacy.
- Require explicit operator consent and record third-party branded-content / own-brand declarations separately; the UI prevents both being selected simultaneously.
- Add status refresh and operator reconciliation for uncertain outcomes; `send_to_inbox` is shown as a TikTok-app handoff rather than a retry button.
- Display TikTok owned-video metrics and retain approved jobs in the queue until both YouTube and TikTok are complete.
- If manual staging changes the approved fingerprint, the UI stops and requires a fresh human review.

## Validation boundary

CI pending. No TikTok developer app, OAuth credentials, real creator account, or live publish request was used. Public posting remains disabled; only `SELF_ONLY` is exposed.
