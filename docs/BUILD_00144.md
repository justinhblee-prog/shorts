# BUILD-00144 — reject malformed metrics in performance insights

## Problem

Performance diagnostics converted retention coordinates with `float()` without excluding booleans. Python treats booleans as numbers, so `True` and `False` could appear as valid retention values. Duration bucketing also allowed NaN to fall through all comparisons and be labeled as `over_60s`.

## Changes

- Reject boolean retention coordinates before numeric conversion.
- Handle numeric conversion overflow in retention and duration helpers.
- Require finite positive duration values before assigning a duration bucket.
- Preserve valid numeric strings and normal duration bucketing behavior.
- Add regression tests for booleans, NaN, infinities and overflowing numeric strings.
