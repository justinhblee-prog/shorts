# BUILD-00152 — duplicate performance outcome isolation

## Defect
Recommendation evaluation previously stored performance rows in a dictionary keyed by job ID. When one payload contained duplicate rows for the same job, the final row silently overwrote earlier values. The resulting evaluation depended on input order and could select one of conflicting snapshots without evidence.

## Change
- Track normalized production job IDs within each evaluation payload.
- Exclude a job from measured outcomes when it appears more than once.
- Keep unique job measurements unchanged.
- Add regression coverage with conflicting duplicate values and a valid unique measurement.

## Safety boundary
The evaluator remains observational and selection-biased. Ranking score adjustment remains disabled. No live provider/account/deployment validation is claimed.

## Validation
The complete scripts/validate.sh workflow is tracked by the pull request.
