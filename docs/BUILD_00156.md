# BUILD-00156 — malformed brand profile isolation

## Finding
The trend-ranking boundary accepts dictionary-shaped brand records but assumes their nested `config` is also a dictionary and profile text fields are strings. A persisted profile with a scalar config or numeric/list text value can raise an attribute/type error and abort an otherwise valid ranking batch.

## Change
- Normalize nested brand config to an empty mapping when its type is invalid.
- Convert optional profile text fields to safe strings before tokenization.
- Add a mixed-batch regression proving malformed profiles do not prevent a valid brand from ranking.
