# BUILD-00024 — Approval artifact integrity gate

**Date:** 2026-11-16  
**Scope:** Prevent a YouTube upload from using production artifacts that changed after human approval.

## Change

Before an upload attempt is created, the upload store compares the latest human-approved artifact snapshot against the current ordered `production_artifacts` rows. The comparison includes stage, artifact type, artifact URL and parsed metadata. Additions, removals, modifications, malformed snapshots, and order changes invalidate the prior approval.

The check runs independently of the policy version/date freshness gate. A current policy record cannot make a changed artifact set eligible for upload.

## Regression coverage

- Modifying metadata on an already-approved rendering artifact blocks upload.
- Adding a new artifact after approval blocks upload.
- Both checks assert no upload record/attempt is initialized.

## Validation boundary

CI validation pending on this branch. This gate does not by itself fingerprint the bytes of a staged local media file; byte-level media immutability remains a separate control to validate.
